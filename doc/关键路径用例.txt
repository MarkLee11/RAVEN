===============================================================================
RAVEN 关键路径用例（Phase 4）
===============================================================================
日期：2026-09-20

一、认证与访问路径
-------------------------------------------------------------------------------
CP-01 未登录访问受保护页
- 步骤：直接访问 `/submit` 或 `/favorites/bars`
- 预期：跳转 `/profile`，登录后回跳原路径

CP-02 登录后提交评论
- 步骤：登录 -> 进入 club/bar 详情 -> 点击 Add Review -> 提交
- 预期：提交成功后回到详情页，评论立即回显（optimistic）

CP-03 登出后访问受保护页
- 步骤：登录 -> 登出 -> 访问 `/favorites/clubs`
- 预期：再次要求登录

二、浏览与详情路径
-------------------------------------------------------------------------------
CP-04 Clubs 列表筛选
- 步骤：切换 district + construction + payment
- 预期：列表刷新，无控制台错误，空结果有提示

CP-05 Bars 列表筛选
- 步骤：切换 district + themes
- 预期：列表刷新，收藏状态同步

CP-06 Club/Bar 详情加载失败兜底
- 步骤：模拟接口失败/无数据
- 预期：显示错误文案，可点击 Try Again 重试

三、收藏路径
-------------------------------------------------------------------------------
CP-07 收藏与取消收藏
- 步骤：详情页点击收藏星标；在 favorites 页删除
- 预期：状态即时更新，刷新后与数据库一致

CP-08 收藏空态
- 步骤：清空收藏后进入 favorites 页面
- 预期：显示空态文案与返回入口

四、个人中心路径
-------------------------------------------------------------------------------
CP-09 Deathmarch 数据显示
- 步骤：登录后进入 Profile
- 预期：显示 clubs/bars 已访问计数与总数

CP-10 Echo 最新评论展示
- 步骤：有评论数据用户进入 Profile
- 预期：展示最近评论、评分条、日期，字段映射正确

五、回归检查命令
-------------------------------------------------------------------------------
- `npm run lint`
- `npm run typecheck`
- `npm run test`
- `npm run build`
- `npm run check-all`
