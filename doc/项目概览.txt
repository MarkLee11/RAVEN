一、项目简介
--------------------------------------------------------------------------------
RAVEN 是一款面向柏林夜生活文化的移动端优先 Web 应用，帮助用户发现、评价和
追踪夜店（Clubs）与酒吧（Bars）。设计风格偏赛博朋克/柏林地下文化，强调沉浸式
体验与情感化交互。

核心理念:
  - Discover  探索柏林特色夜生活场所
  - Experience 记录并分享真实夜生活体验
  - Transcend  通过 "Deathmarch" 进度系统激励用户探索更多场所


二、技术栈
--------------------------------------------------------------------------------
前端:
  - React 18.3 + TypeScript 5.5
  - Vite 5.4 (构建工具)
  - Tailwind CSS 3.4 (样式)
  - Framer Motion 12 (动画)
  - React Router 7.8 (路由)
  - Lucide React (图标)

后端与数据库:
  - Supabase (PostgreSQL + Auth + RLS + 实时 API)
  - @supabase/supabase-js 2.55

部署:
  - Netlify (主部署: ravenberlin.netlify.app)
  - Vercel (vercel.json 配置了 SPA 重写)
  - netlify.toml 定义构建与开发代理


三、核心功能
--------------------------------------------------------------------------------

1. 首页 (CORE) - Landing.tsx
   - 多语言 WordStream 评论流动画 (WordStreamReviews 组件)
   - 3D 卡片旋转、扫描线、绿色烟雾等视觉效果
   - 入口导航至 Clubs / Bars

2. 夜店发现 (CLUBS) - Clubs.tsx / ClubDetail.tsx
   - 夜店列表浏览与多维度筛选 (地区、建筑特征、支付方式等)
   - 详情页展示评分、评论、实时 Vibe 信息
   - 评分维度: Music, Vibe, Crowd, Safety (0-100)
   - 支持收藏

3. 酒吧发现 (BARS) - Bars.tsx / BarDetail.tsx
   - 酒吧列表浏览与多维度筛选 (地区 + 5 类主题标签)
   - 主题分类: drinks, style, architecture, vibe, music
   - 评分维度: Quality, Vibe, Price, Friendliness (0-100)
   - 评论分页、收藏功能

4. 评论系统 - SubmitReview.tsx / reviewsService.ts
   - 登录用户可提交匿名评论
   - 支持 Club 与 Bar 两种场馆类型
   - 乐观更新: 提交后立即在详情页显示
   - 自动聚合场馆平均评分

5. 用户档案 (ID) - Profile.tsx
   - Supabase 邮箱密码注册/登录
   - Deathmarch 进度: 已访问夜店数/总数、酒吧数/总数
   - Echo 记忆: 分页展示用户评论历史
   - Graveyard 收藏: 跳转 FavoriteClubs / FavoriteBars
   - 最新评论预览

6. 收藏系统 - FavoriteClubs.tsx / FavoriteBars.tsx
   - favoritesService 管理用户收藏
   - 支持 club / bar 两种 venue_type

7. 实时 Vibe - vibeService.ts
   - club_tonight_vibe 表集成
   - 展示门口严格度、音乐、人群等实时氛围数据

8. 底部导航 - RavenBottomNav.tsx
   - 四个 Tab: CORE | CLUBS | BARS | ID
   - 移动端触摸优化 (onTouchStart 消除 300ms 延迟)

六、启动方式
--------------------------------------------------------------------------------

环境要求:
  - Node.js 16+ (推荐 18+)
  - npm 8+ 或 yarn
  - Supabase 账号与项目

步骤:

  1. 克隆并安装依赖
     git clone <repository-url>
     cd RAVEN
     npm install

  2. 配置环境变量
     复制 .env.example 为 .env，填入:
       VITE_SUPABASE_URL=你的 Supabase 项目 URL
       VITE_SUPABASE_ANON_KEY=你的 Supabase anon key

  3. 初始化数据库 (在 Supabase SQL Editor 中按顺序执行)
     sql/bars_v2_00_create_all_bar_tables.sql
     sql/bars_v2_08_fix_view_rls.sql
     (以及 clubs 相关迁移，见 supabase/migrations/)

  4. 启动开发服务器
     npm run dev
     访问: http://localhost:5173

  5. 其他命令
     npm run build      生产构建 (输出到 dist/)
     npm run preview    预览生产构建
     npm run lint       ESLint 代码检查
     npm run dev:live   Netlify Dev 联调 (端口 8888 代理 5173)

  6. 数据脚本 (scripts/ 目录，需单独 npm install)
     scripts/setup-env.ps1           PowerShell 设置 Supabase 环境变量
     scripts/import-mock-data-supabase.js  导入模拟数据
     scripts/generate-bar-mock-reviews.js  生成酒吧评论数据
     scripts/berlin-bars-scraper.js        柏林酒吧爬虫


七、环境变量
--------------------------------------------------------------------------------
变量名                    说明                          获取方式
VITE_SUPABASE_URL         Supabase 项目 URL             Dashboard > Settings > API
VITE_SUPABASE_ANON_KEY    Supabase 匿名公钥             Dashboard > Settings > API

注意: 仅使用 anon key，勿将 service_role key 暴露在前端；.env 不要提交到 Git。


八、数据库概览
--------------------------------------------------------------------------------
主要表:
  clubs, bars              场馆主表
  districts                柏林地区
  themes, bar_themes       主题标签系统
  club_reviews, bar_reviews 用户评论
  club_ratings, bar_ratings 默认评分
  bar_locations            酒吧地址
  favorites                用户收藏
  club_tonight_vibe        实时氛围

安全:
  - Row Level Security (RLS) 已启用
  - 公开读取场馆与评论，写入需认证
  - 用户只能管理自己的 favorites
