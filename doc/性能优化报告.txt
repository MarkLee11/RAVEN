===============================================================================
RAVEN 性能优化报告（Phase 6）
===============================================================================
日期：2026-09-20

一、目标
-------------------------------------------------------------------------------
- 降低首屏包体与初次解析压力
- 为后续移动端性能优化打基础

二、实施内容
-------------------------------------------------------------------------------
1) 路由级代码分割
- 文件：`src/App.tsx`
- 改动：
  - 将主要 route 页面改为 `React.lazy` 动态加载
  - 使用 `Suspense` 提供统一 loading fallback
- 覆盖路由：
  - Landing / Clubs / ClubDetail / Bars / BarDetail / SubmitReview / Profile / FavoriteBars / FavoriteClubs

2) 构建验证
- 命令：`npm run build`
- 结果：由单个大 chunk 切分为多 route chunk（见下）

三、构建产物对比（关键指标）
-------------------------------------------------------------------------------
优化前（单大包场景）：
- `dist/assets/index-*.js` ≈ 532 KB（gzip ≈ 157 KB）

优化后（路由拆分后）：
- `dist/assets/index-*.js` ≈ 315.59 KB（gzip ≈ 96.89 KB）
- 其余业务页面拆分为独立 chunk（约 4 KB ~ 20 KB）

结论：
- 初始主包显著下降，页面按需加载生效。

四、风险与后续建议
-------------------------------------------------------------------------------
- 当前 `Card` 相关 chunk 体积仍较大（~114 KB），建议后续排查：
  - 是否可进一步拆分第三方动画/图标依赖
  - 检查重复依赖与共享 chunk 策略
- 在真实设备上补充 Lighthouse 移动端基线测试，并记录 TTI/FCP/LCP。
